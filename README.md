# VStream VCam — Android Virtual Camera Project

Generated by VStream Studio.

## Features Included
- **Image Feed**: Pick any image from Android storage and render it continuously at 30fps onto the virtual camera surface.
- **Video Upload Feed**: Pick MP4/MOV/WebM videos using Media3 ExoPlayer with looping, mute control, and center-crop scaling.
- **OBS Stream Input**: Connect directly to your OBS Studio stream over local Wi-Fi (`rtsp://`, `rtmp://`, or HTTP stream URL).
- **Mode**: LSPosed / Xposed Camera2 Hook (for rooted / LSPosed Android devices)

## How to Build the APK (2 Ways)

### Option 1: Free Cloud Build via GitHub Actions (No PC / Android Studio Needed)
1. Create a new GitHub repository and upload all files from this ZIP.
2. Open the **Actions** tab on GitHub and click **Build Android VCam APK** -> **Run workflow**.
3. Wait ~3 minutes and download the compiled `.apk` from **Artifacts**.

### Option 2: Build Locally in Android Studio
1. Open this unzipped folder in **Android Studio**.
2. Wait for Gradle sync to complete.
3. Click **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
4. Install `app/build/outputs/apk/debug/app-debug.apk` onto your Android device.

## Connecting OBS Studio to Android
1. Install **obs-rtspserver** (or run a local MediaMTX / Nginx-RTMP server on your PC).
2. Stream from OBS to your PC local IP (e.g. `rtsp://192.168.1.42:8554/obs`).
3. Enter that exact URL inside the **OBS** tab of this Android app and tap **Connect OBS Stream**.
